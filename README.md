# Bioinformática para Tecnologia e Saúde

Material didático para aulas de Bioinformática com abordagem introdutória, conectando **Biologia, Computação, Ciência de Dados e Saúde**.

> Foco do repositório: compreender como dados biológicos podem ser armazenados, processados e analisados computacionalmente, sem exigir formação prévia em Biologia Molecular avançada.

## Aulas

### Aula 01 - Bioinformática: quando a Biologia vira dado

Nesta aula, o estudante conhece:

- o conceito de Bioinformática;
- a relação entre Biologia, Computação e Estatística;
- DNA, genes, proteínas e sequências como dados computacionais;
- bancos biológicos como NCBI/GenBank, UniProt e PDB;
- a ideia de análise *in silico*;
- a importância do pré-processamento e da qualidade dos dados;
- uma primeira análise de sequências usando Python.

➡️ [Acessar a Aula 01](aula01/README.md)
