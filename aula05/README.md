## Objetivo

Transformar uma base CSV sintética em tabelas, resumos e gráficos, seguindo o fluxo:

```text
carregar → conhecer → preparar → resumir → visualizar → interpretar
```

## Conteúdos

- variáveis, listas e dicionários;
- leitura de arquivos CSV;
- organização de dados com pandas;
- valores ausentes;
- tamanho das sequências;
- quantidade e percentual GC;
- filtros e agrupamentos;
- gráficos de barras, linhas, histograma e dispersão;
- interpretação científica responsável.
