1. Organização da base

Em uma tabela, cada linha representa um registro ou amostra e cada coluna representa uma variável. Confira os nomes, os tipos de informação e a consistência dos registros antes de interpretar os dados.

2. Arquivos CSV

CSV é um formato de tabela em texto. Nas aulas, a base didática é aberta com pandas e pd.read_csv('base_python0_bioinformatica.csv'). O arquivo deve estar disponível no ambiente usado, como no Colab.

3. Inspeção inicial com pandas

Use head() para observar linhas iniciais; shape para ver quantidade de linhas e colunas; columns para conferir os nomes; info() para observar estrutura e tipos; e isna().sum() para contar valores ausentes por coluna.

4. Qualidade dos dados e valores ausentes

Verifique se os dados estão completos, consistentes, válidos, coerentes e sem duplicações indevidas. Um campo vazio não deve ser automaticamente substituído por zero: primeiro entenda o que a ausência significa e registre qualquer tratamento realizado.

5. Noções básicas de Python

Uma variável guarda um valor. input() recebe uma entrada e print() exibe uma saída. Os tipos apresentados incluem texto (str), inteiro (int), decimal (float) e lógico (bool). A sequência de trabalho pode ser pensada como entrada → processamento → saída.

6. Listas, dicionários e repetição

Listas organizam vários valores em sequência; dicionários associam chaves a valores; e o laço for repete uma ação para os elementos de uma coleção. Esses recursos ajudam a organizar e percorrer informações nos exemplos vistos em aula.

7. DataFrame e coluna calculada

Um DataFrame é uma estrutura tabular do pandas. A aula usa a base para observar os registros e criar uma coluna derivada, como o comprimento da sequência. Uma coluna calculada deve corresponder ao significado dos dados usados no cálculo.

8. Escolha e leitura de gráficos

Gráfico de barras compara categorias; linha mostra variação ao longo de uma sequência ou período; setores representam partes de um total; dispersão ajuda a observar relação entre duas variáveis; histograma mostra distribuição de valores. Leia título, eixos, unidades e escala.

9. Interpretação responsável

Um gráfico resume os dados observados, mas não prova por si só que uma variável causou outra. Considere a qualidade e o contexto da base antes de tirar conclusões.
